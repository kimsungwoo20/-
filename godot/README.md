# 개미 RTS — 고닷 시제품

`docs/system-design.md` 기획서의 공통 시스템을 옮긴 첫 시제품이다. 고닷 4.3 기준.

## 그림과 소리

- 그림은 모두 코드로 그린다(scripts/art.gd). 개미는 머리·가슴·배 세 마디에 다리 6개와 더듬이, 걸을 때 다리가 움직인다. 몸통은 플레이어 색, 머리·턱 모양으로 진영을 구분한다(불개미 침, 잎꾼개미 톱니 턱, 베짜기개미 긴 다리, 함정턱개미 곧고 긴 턱, 군대개미 낫 턱)
- 건물도 진영마다 모양이 다르다: 불개미 흙 둔덕, 잎꾼개미 균사 덩어리, 베짜기개미 엮은 잎, 함정턱개미 땅속 굴, 군대개미 엉킨 개미 무리(행군 중이면 꿈틀거림). 가운데 표시로 종류(여왕·교차한 턱·방패·날개·육각형)를 구분한다
- 효과음은 합성해서 만든다(tools/make_sfx.py → sounds/). 화면에 보이는 곳의 소리만 나고, M 키로 끄고 켠다
- 건물이 공격받으면 경고음과 함께 미니맵에 빨간 원이 표시된다

## 인공지능

- 전장의 안개를 따른다: 자기 팀이 본 적 있는 적 건물만 기억해 공격하고(은폐 건물은 감지해야 안다), 아는 것이 없으면 상대 시작 위치로 정찰을 간다
- 인구가 차면 둥지 등급 상승 → 확장 → 군체 확대 연구 순으로 한도를 늘린다
- 진영별 운영: 불개미 빠른 확장과 뗏목 상륙, 잎꾼개미 정원 조절과 공생균 살포병 동행, 베짜기개미 영역을 이어 붙이는 확장, 함정턱개미 적은 일꾼과 유인병 동행(경보 페로몬), 군대개미 이주(준비 → 이동 → 정착)·본진 옆 위성 둥지·약탈병 무리
- 리그전: `GODOT=godot tools/tournament.sh` (godot 폴더에서). 결과 기록은 docs/roadmap.md


| 진영 | 특징 |
|---|---|
| 불개미 | 침병·병정개미 2기 한 조, 싼 위성 둥지, 무거운 유지비, 독, 공중 물량 |
| 군대개미 | 건물이 야영 ↔ 행군으로 움직임, 건물 재료 -40% 대신 건물당 인구 3, 약탈, 진딧물은 도살만, 좁은 시야 |
| 함정턱개미 | 턱 타격(충전되면 3배 + 밀쳐내기), 매복 은신, 턱 도약, 은폐 건물, 비싼 일꾼(75)·운반 +5 |
| 베짜기개미 | 수관 영역(건물이 영역을 만들고 영역 안에만 건설), 영역 안에서 빠르고 회복, 원거리 산성·끌어당기기·고정·장막 |
| 잎꾼개미 | 균류 정원(본진 안 정원사가 재료를 식량으로 변환), 재료 운반 +5, 대턱·초대형 병정, 회복·포자 폭격 |

## 메인 화면

게임을 열면 메인 화면이 나온다. 다섯 진영의 개미 행렬이 지나가는 배경 위에 메뉴가 있다.

- 혼자 하기: 방 화면(인공지능과 대전)
- 온라인 대전: 방 화면(방 만들기·방 코드로 참가)
- 진영 소개: 진영별 개미·둥지 그림, 콘셉트, 강점, 약점, 상성, 대표 유닛
- 조작법, 설정(소리 끄기·음량), 데스크톱에서는 끝내기

## 방 화면

메인 화면에서 혼자 하기 또는 온라인 대전을 고르면 방 화면이 나온다. 왼쪽 위 "← 처음 화면"으로 돌아간다. 자리 5개를 나 / 인공지능 / 비움으로 정하고, 자리마다 진영(무작위 가능)·팀·난이도를 고른다.

- 개인전 또는 팀전. 팀전은 같은 팀끼리 공격하지 않고 시야와 은신 감지를 함께 쓴다. 마지막까지 남은 팀이 승리
- 지도 크기: 자동(2~3인 보통, 4~5인 크게) / 작게 2600×1600 / 보통 3200×2000 / 크게 4800×3000 / 아주 크게 6400×4000. 큰 지도일수록 기지 사이가 멀고 확장 지점이 많다. 4~5인 판은 최대 인구 150
- 인공지능 난이도: 쉬움 / 보통 / 어려움(채집 +20%)
- 팀전 "인원 불균형 보정": 인원이 적은 팀의 채집 속도 증가
- 내가 탈락하면 판이 끝난다(관전 없음). 결과 화면에서 "다시 하기" 또는 "방으로"
- 온라인: "방 만들기"로 방장이 되면 방 코드가 나온다. 친구는 방 코드를 넣고 "참가". 방장 화면에서 참가자는 "사람(참가자)" 자리(없으면 빈자리)에 앉고, 방장이 시작한다
  - 웹에서는 연결 중개 서버 주소가 필요하다: 게임 주소 끝에 `?signal=wss://서버주소` (server/README.md)
  - 데스크톱에서는 방 코드 대신 `주소:포트`(기본 7777)
  - 접속이 끊기면: 팀전이고 접속 중인 아군 사람이 있으면 그 아군이 조종, 아니면 인공지능이 대신. 같은 방에 다시 참가하면 돌려받는다
  - 방장이 나가면 판이 끝난다

주소로 바로 시작(방 화면 건너뜀): `?me=leaf&ai=fire&map=large` (진영 fire / leaf / weaver / trap / army, 지도 small / medium / large / huge).
화면 없이 실행할 때: `-- --p0=leaf --p1=fire`, 여러 명은 `-- --players=fire,leaf,trap --teams=0,0,1 --diffs=normal,hard,easy --map=huge`.

## 실행

1. 고닷 4.3 에디터에서 이 폴더(`godot/`)의 `project.godot` 을 연다.
2. F5 로 실행한다.

웹 버전 다시 만들기(고닷 4.3 웹 내보내기 템플릿 필요). 결과물은 `docs/play/` 에 생긴다:

```
godot --headless --path godot --export-release "Web" ../docs/play/index.html
```

규칙 점검(공중·거점화·등급 조건·진영 능력 등):

```
godot --headless --path godot -s tests/smoke.gd -- --sandbox
```

판 점검(2~5인 지도, 팀, 승패, 난이도, 방 화면, 인공지능 판단):

```
godot --headless --path godot -s tests/match.gd
```

웹 버전 점검용: 주소 끝에 `?debug` 를 붙이면 식량·재료 5000 으로 시작한다(예: `.../play/?debug`).

온라인 점검(방장·참가자·재접속을 각각 다른 프로그램으로):

```
GODOT=godot tools/net_test.sh ffa
GODOT=godot tools/net_test.sh team
```

자동 대전 점검(인공지능 대 인공지능, 화면 없이):

```
godot --headless --path godot -- --autotest
```

## 구현된 것

- 자원 2종(식량·재료), 자원 지점 5종(씨앗 더미, 진딧물 군락, 낙엽 더미, 살아있는 식물, 고목·수지), 채집 슬롯, 고갈·재생·휴면
- 본진(주 둥지 등급 I~III, 위성 둥지), 전투 생산, 방어 생산, 특수 생산(주 둥지 II), 연구소(1개 제한)
- 생산 대기열(5), 예약 시 지불, 취소 환불, 인구 한도, 유지비(식량 수입 비율 감소)
- 여왕 계승(주 둥지 파괴 시 위성 둥지 승격, 등급 -1, 일꾼 생산 60초 정지), 본진 전멸 시 패배
- 불개미: 일꾼, 침병(2기 한 조), 병정개미(2기 한 조), 분사병(T2), 폭군 대병(T3, 침병 강화), 방벽 개미(거점화),
  날개 정찰병·혼인비행 떼(공중), 싼 위성 둥지, 가중 유지비
- 공중 규칙: 근접 지상 유닛은 공중을 공격하지 못하고, 원거리 유닛과 본진만 대공 가능
- 연구 29종(연구소 탭: 신체 / 군체 / 고유)
  - 신체: 큰턱·분비샘·외골격(각 3단계), 체격 증대(2), 다리 근육, 비행 근육, 솔레놉신 독침(중첩 독)
  - 군체: 산란 촉진, 운반낭 발달, 군체 확대, 육아 효율, 영양 교환(각 2단계)
  - 고유(불개미): 다여왕 군체, 경보 페로몬, 폭군의 혈통(폭군 대병 해금), 분기 진화 끝없는 물결 / 타오르는 독(둘 중 하나)
  - 진행 1 + 예약 3, 앞 단계는 예약만 되어 있어도 다음 단계 예약 가능, 연구소 파괴 시 진행·예약 연구 환불(완료 연구 유지)
- 지도 요소
  - 중립 생물 3단계: 딱정벌레 유충(기지 근처 2마리 무리), 거미(측면), 사마귀(중앙 고목 옆). 먼저 공격하지 않고, 공격받으면 같은 무리가 반격하며, 너무 멀리 끌려 나오면 돌아간다. 전멸하면 180초 뒤 다시 나타난다
  - 사체: 중립 생물이 죽으면 식량 사체(300 / 700 / 1500)를 남기고, 240초마다 맵 중앙에 큰 사체(800)가 떨어진다. 사체는 180초 뒤 썩어 사라진다
  - 진딧물 도살: 전투 유닛으로 진딧물 군락을 오른쪽 클릭하면 공격. 도살한 쪽이 식량 150, 군락은 120초 뒤 재생
  - 전장의 안개: 지금 보이는 곳 / 본 적 있는 곳 / 본 적 없는 곳. 시야 밖 적 유닛은 숨고, 한 번 본 적 건물은 남는다
  - 은신과 감지: 은신 유닛은 감지 범위(본진, 날개 정찰병) 안에서만 보이고 공격받는다. 아직 은신 유닛을 가진 진영은 없다(함정턱개미에서 사용)
- 지형과 길찾기
  - 물: 지상 유닛 통과 불가. 절벽: 지상 유닛과 뗏목 통과 불가. 수목: 지상 유닛 이동 속도 70%. 공중 유닛은 모두 무시
  - 지상 유닛은 장애물을 돌아가는 길을 찾아 이동한다. 건물은 맨땅에만 지을 수 있다
  - 지도: 기지와 중앙 사이의 호수, 위·아래 길목을 만드는 절벽, 곳곳의 수목(좌우 대칭)
  - 뗏목단(고유 진화 "뗏목 진형" 필요): 물 위를 다니는 수송 유닛. 유닛을 선택하고 뗏목단을 오른쪽 클릭하면 탑승(인구 8까지), 뗏목단의 "하선" 버튼으로 주변 땅에 내린다. 뗏목단이 죽으면 탑승 유닛도 죽는다
- 군대개미
  - 야영과 행군: 건물 선택 후 "행군 준비"(10초) → 오른쪽 클릭으로 이동 → "야영"(15초). 주 둥지의 "군체 전체 행군 / 야영"으로 한꺼번에 전환하고, 주 둥지를 움직이면 다른 건물이 대형을 유지하며 따라온다
  - 행군 중: 유닛 생산 속도 50%, 일꾼 생산·연구·자원 반납 정지, 받는 피해 +25%, 둥지 수비 공격 없음. 수목·물 위나 다른 건물과 겹치는 자리에는 야영할 수 없다
  - 살아있는 건축: 건물 재료 비용 -40%, 본진 외 건물 1동당 인구 3
  - 약탈: 적 일꾼 처치 시 식량(비용의 20%), 적 건물 파괴 시 식량과 재료
  - 포식: 진딧물은 채집하지 못하고 도살만(일꾼으로 오른쪽 클릭해도 공격). 사체 채집 시간 60%
  - 유닛: 약탈병(빠름), 낫턱 병정, 포식 대군(범위 피해, 처치 시 회복), 수호병(행군 중인 건물 근처에서 피해 -30%), 다리 개미(거점화하면 주변 물·절벽이 다리가 되고 가까운 공중 유닛을 공격), 선발 정찰병(넓은 시야, 감지), 운반병(이동식 반납 지점), 날개 수개미(공중 전용 요격)
  - 연구: 갈고리 턱(맞은 적 감속), 대행군, 약탈 본능, 살아있는 다리, 포식의 물결, 분기 영원한 유랑 / 정주기 산란
- 함정턱개미
  - 턱 타격: 4초 동안 공격하지 않으면 다음 공격이 3배 피해 + 밀쳐내기. 충전되면 유닛 앞에 노란 점이 보인다
  - 은폐 건물: 본진 외 건물은 감지 범위(본진·정찰 유닛) 안에서만 보이고 공격받는다
  - 일꾼: 식량 75, 무엇이든 5 더 나르고 공격력 6
  - 유닛: 격발병, 도약 사냥꾼(턱 타격 후 뒤로 도약, 공중 공격 가능), 대왕 포식자(직선 범위), 덫지기(거점화하면 은신, 첫 타격 2배), 굴 수호자(건물 근처 충전 2초), 그림자 척후(늘 은신, 감지), 유인병(경보 페로몬 버튼), 낙하 사냥꾼(공중 급강하 후 5초 착지)
  - 공격하면 은신이 풀리고 3초 뒤 다시 숨는다
  - 연구: 강화 격발(밀쳐내기 2배 + 기절), 완전 매복, 턱 도약 숙련(절벽·물 넘기), 연쇄 격발, 포식자의 왕, 분기 고독한 사냥꾼 / 사냥 무리
- 베짜기개미
  - 수관 영역: 건물마다 영역 원(잎 궁전 280, 수관 초소 300, 그 외 220)이 생기고 건물은 영역 안에만 지을 수 있다. 영역이 맞닿은 건물끼리 이어져 네트워크가 된다
  - 주 둥지와 이어진 영역 안: 지상 유닛 이동 +15%, 초당 1 회복, 채집 +20%. 끊어진 구역: 보너스 없음, 건물 생산 속도 70%. 영역 밖: 지상 유닛 이동 -15%
  - 수목 지대에서 느려지지 않고 수목 위에도 건설 가능
