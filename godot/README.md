# 개미 RTS — 고닷 시제품

`docs/system-design.md` 기획서의 공통 시스템을 옮긴 첫 시제품이다. 고닷 4.3 기준.

## 실행

1. 고닷 4.3 에디터에서 이 폴더(`godot/`)의 `project.godot` 을 연다.
2. F5 로 실행한다.

자동 대전 점검(인공지능 대 인공지능, 화면 없이):

```
godot --headless --path godot -- --autotest
```

## 구현된 것

- 자원 2종(식량·재료), 자원 지점 5종(씨앗 더미, 진딧물 군락, 낙엽 더미, 살아있는 식물, 고목·수지), 채집 슬롯, 고갈·재생·휴면
- 본진(주 둥지 등급 I~III, 위성 둥지), 전투 생산, 방어 생산, 연구소(1개 제한)
- 생산 대기열(5), 예약 시 지불, 취소 환불, 인구 한도, 유지비(식량 수입 비율 감소)
- 여왕 계승(주 둥지 파괴 시 위성 둥지 승격, 등급 -1, 일꾼 생산 60초 정지), 본진 전멸 시 패배
- 불개미: 일꾼, 침병(2기 한 조), 병정개미(2기 한 조), 분사병(T2), 싼 위성 둥지, 가중 유지비
- 연구 4종: 큰턱 강화 I, 외골격 경화 I, 운반낭 발달 I, 군체 확대 I
- 사람 1 대 인공지능 1

## 아직 없는 것

특수 생산 건물과 공중 유닛, T3 유닛, 고유 진화, 사체·중립 생물, 진딧물 도살, 거점화, 은신, 전장의 안개,
지형(물·절벽·수목), 나머지 4개 진영, 방·다인 대전, 웹 내보내기.

## 조작

| 입력 | 동작 |
|---|---|
| 왼쪽 클릭 / 드래그 | 선택 |
| 오른쪽 클릭 | 이동, 공격, 채집, 건설 지원, (건물 선택 시) 집결 지점 |
| A 후 왼쪽 클릭 | 공격 이동 |
| S | 정지 |
| Q W E R T | 명령 버튼 1~5 |
| 방향키, 가운데 버튼 드래그, 미니맵 클릭 | 화면 이동 |
| 휠 | 확대/축소 |
