# 개미 RTS — 고닷 시제품

`docs/system-design.md` 기획서의 공통 시스템을 옮긴 첫 시제품이다. 고닷 4.3 기준.

## 진영

| 진영 | 특징 |
|---|---|
| 불개미 | 침병·병정개미 2기 한 조, 싼 위성 둥지, 무거운 유지비, 독, 공중 물량 |
| 잎꾼개미 | 균류 정원(본진 안 정원사가 재료를 식량으로 변환), 재료 운반 +5, 대턱·초대형 병정, 회복·포자 폭격 |

진영 고르기(방 화면은 9단계): 웹 주소 끝에 `?me=leaf&ai=fire` 처럼 붙인다. 기본은 나 불개미, 상대 잎꾼개미.
화면 없이 실행할 때는 `-- --p0=leaf --p1=fire`.

## 실행

1. 고닷 4.3 에디터에서 이 폴더(`godot/`)의 `project.godot` 을 연다.
2. F5 로 실행한다.

웹 버전 다시 만들기(고닷 4.3 웹 내보내기 템플릿 필요). 결과물은 `docs/play/` 에 생긴다:

```
godot --headless --path godot --export-release "Web" ../docs/play/index.html
```

규칙 점검(공중·거점화·등급 조건 등):

```
godot --headless --path godot -s tests/smoke.gd -- --sandbox
```

웹 버전 점검용: 주소 끝에 `?debug` 를 붙이면 식량·재료 5000 으로 시작한다(예: `.../play/?debug`).

자동 대전 점검(인공지능 대 인공지능, 화면 없이):

```
godot --headless --path godot -- --autotest
```

## 구현된 것

- 자원 2종(식량·재료), 자원 지점 5종(씨앗 더미, 진딧물 군락, 낙엽 더미, 살아있는 식물, 고목·수지), 채집 슬롯, 고갈·재생·휴면
- 본진(주 둥지 등급 I~III, 위성 둥지), 전투 생산, 방어 생산, 특수 생산(주 둥지 II), 연구소(1개 제한)
- 생산 대기열(5), 예약 시 지불, 취소 환불, 인구 한도, 유지비(식량 수입 비율 감소)
- 여왕 계승(주 둥지 파괴 시 위성 둥지 승격, 등급 -1, 일꾼 생산 60초 정지), 본진 전멸 시 패배
- 불개미: 일꾼, 침병(2기 한 조), 병정개미(2기 한 조), 분사병(T2), 폭군 대병(T3, 침병 강화), 방벽 개미(거점화),
  날개 정찰병·혼인비행 떼(공중), 싼 위성 둥지, 가중 유지비
- 공중 규칙: 근접 지상 유닛은 공중을 공격하지 못하고, 원거리 유닛과 본진만 대공 가능
- 연구 29종(연구소 탭: 신체 / 군체 / 고유)
  - 신체: 큰턱·분비샘·외골격(각 3단계), 체격 증대(2), 다리 근육, 비행 근육, 솔레놉신 독침(중첩 독)
  - 군체: 산란 촉진, 운반낭 발달, 군체 확대, 육아 효율, 영양 교환(각 2단계)
  - 고유(불개미): 다여왕 군체, 경보 페로몬, 폭군의 혈통(폭군 대병 해금), 분기 진화 끝없는 물결 / 타오르는 독(둘 중 하나)
  - 진행 1 + 예약 3, 앞 단계는 예약만 되어 있어도 다음 단계 예약 가능, 연구소 파괴 시 진행·예약 연구 환불(완료 연구 유지)
- 지도 요소
  - 중립 생물 3단계: 딱정벌레 유충(기지 근처 2마리 무리), 거미(측면), 사마귀(중앙 고목 옆). 먼저 공격하지 않고, 공격받으면 같은 무리가 반격하며, 너무 멀리 끌려 나오면 돌아간다. 전멸하면 180초 뒤 다시 나타난다
  - 사체: 중립 생물이 죽으면 식량 사체(300 / 700 / 1500)를 남기고, 240초마다 맵 중앙에 큰 사체(800)가 떨어진다. 사체는 180초 뒤 썩어 사라진다
  - 진딧물 도살: 전투 유닛으로 진딧물 군락을 오른쪽 클릭하면 공격. 도살한 쪽이 식량 150, 군락은 120초 뒤 재생
  - 전장의 안개: 지금 보이는 곳 / 본 적 있는 곳 / 본 적 없는 곳. 시야 밖 적 유닛은 숨고, 한 번 본 적 건물은 남는다
  - 은신과 감지: 은신 유닛은 감지 범위(본진, 날개 정찰병) 안에서만 보이고 공격받는다. 아직 은신 유닛을 가진 진영은 없다(함정턱개미에서 사용)
- 지형과 길찾기
  - 물: 지상 유닛 통과 불가. 절벽: 지상 유닛과 뗏목 통과 불가. 수목: 지상 유닛 이동 속도 70%. 공중 유닛은 모두 무시
  - 지상 유닛은 장애물을 돌아가는 길을 찾아 이동한다. 건물은 맨땅에만 지을 수 있다
  - 지도: 기지와 중앙 사이의 호수, 위·아래 길목을 만드는 절벽, 곳곳의 수목(좌우 대칭)
  - 뗏목단(고유 진화 "뗏목 진형" 필요): 물 위를 다니는 수송 유닛. 유닛을 선택하고 뗏목단을 오른쪽 클릭하면 탑승(인구 8까지), 뗏목단의 "하선" 버튼으로 주변 땅에 내린다. 뗏목단이 죽으면 탑승 유닛도 죽는다
- 잎꾼개미
  - 균류 정원: 둥지 선택 후 "정원사 추가" 또는 일꾼으로 자기 둥지를 오른쪽 클릭. 슬롯 주 둥지 I/II/III 4/8/12, 위성 둥지 2. 정원사 1기가 분당 재료 45 → 식량 90. 본진 체력 50% 미만이면 효율 절반. 둥지가 무너지면 정원사도 죽는다
  - 유닛: 절단병(연구 효과 1.5배), 대턱 병정, 초대형 병정(건물·거점화 유닛에 2.5배), 문지기(거점화), 호위 소형개미(공중·빠른 적에 1.5배), 길잡이 소형개미(감지, 근처 일꾼 +20% 속도), 공생균 살포병(회복), 포자 살포 날개개미(포자 지대로 건물 지속 피해)
  - 연구: 절단 턱(건물·거점화 +50%), 고수확 균주, 탑승 호위, 항생 공생균, 초대형 계급, 분기 거대 정원 / 전쟁 균류(둥지 버튼으로 전 병력 포자 갑옷)
- 보모 개미: 근처에서 아군 침병·병정개미가 죽으면 가까운 생산 건물의 진행도 +2.5초
- 사람 1 대 인공지능 1

## 아직 없는 것

나머지 3개 진영(베짜기·함정턱·군대개미), 방·다인 대전. 유닛이 건물을 통과해 지나가는 것(건물 충돌 없음)도 아직 그대로다.
